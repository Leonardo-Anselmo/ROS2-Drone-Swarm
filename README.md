# ROS2-Drone-Swarm

An in-progress robotics project exploring coordinated autonomous micro-drone systems using Crazyflie platforms, Python, and ROS 2.

The project focuses on practical hardware experimentation, telemetry and control tooling, and a modular foundation for future multi-agent behaviors. This repository contains the implementation and technical documentation used to build and test the system.
